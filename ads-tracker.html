One-time Google setup
  1. In Google Cloud Console, create or choose a project and enable the AdSense Management API.
  2. Configure Google Auth Platform branding and audience. For a personal testing app, add the AdSense account owner's email as a test user. Add the read-only scope https://www.googleapis.com/auth/adsense.readonly under Data Access.
  3. Create an OAuth client of type Web application. Add this exact Authorized JavaScript origin: https://lesliedaft.github.io.
  4. Copy the client ID (ending in .apps.googleusercontent.com) below. No client secret is needed.
