Rhythm platformer

Geometry Dash 2.0

Master fifteen neon rhythm levels, build up to an Easy Demon challenge, and create your own courses in the level editor.

How to play

Space/click/tap jumps in cube mode. In ship mode hold to rise and release to fall; in ball mode tap to flip gravity. P pauses; R retries; C places practice checkpoints.

Getting started

Use Practice to learn difficult sections with checkpoints. Cube, ship and ball modes respond differently to the same button, so watch mode changes. The level editor lets you build your own courses.
